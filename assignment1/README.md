# Assignment 1:
Code three programs, write a README.md file, and zip all together for submission.
Follow rubric criteria and make sure code passes pylint test.

## Three Programs:
    1. calc_daltons.py
          Calculates the estimated molecular weight of the Protein kinase C beta protein's
          sequence.
    2. calc_number_amino_acids.py
          An interactive code where the user inputs a gene name and sequence length to have
          the average molecular weight calculated for it.
    3. dynamic_protocol.py
          An interactive code based off the given code 'protocol.py'. Calculates dilution 
          math for NaCl and MgCl2 for a desired final volume given solution concentrations.
